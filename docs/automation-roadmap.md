# 增长中枢改造蓝图 —— 以 SKU 为主线的运营自动化链路

> 来源：外部工作流建议（2026-09）—— 不要先堆自动化工具，先建一个以 SKU 为核心的「运营数据中台」，
> 让多平台的数据、库存、内容和利润在同一套规则下运行。本文是该蓝图对本平台的落地对照与分期计划。

## 一、目标链路

```
选品/竞品数据 → SKU 主数据中心 → 商品资料与链接生成 → 各平台备货上架
                                                      ↓
        预警与经营看板 ← 订单/广告/内容/库存数据回流 ←──┘
              ↓                    ↓
        库存/成本/利润          素材库 → 达人建联与视频生成
```

核心原则：**每个 SKU 必须有唯一编码**，五个环节（选品 / 链接 / 达人 / 素材 / 视频）全部挂在编码上；
自动化负责汇总与生成，人工只把关键节点（是否采购、调价与发布、佣金与合同）。

## 二、现状对照（差距分析）

| 蓝图模块 | 自动化结果 | 人工把关 | 平台现状 | 本次改造 |
|---|---|---|---|---|
| 选品分析 | 抓取/导入销量、价格、评价、关键词、竞品、趋势，生成机会评分 | 是否采购、目标售价、首批数量 | 选品测算已有（成本口径） | ✅ 新增 `selection_research` 研究记录 + 机会评分 + 人工判定 |
| 商品上架 | 主数据一键生成西语标题、属性、描述、图片排序，推送各平台草稿 | 合规、类目、价格、库存与最终发布 | 商品主数据已有 | ✅ 新增 `listing_task`（生成稿 + 状态流转） |
| 广告反馈 | 每日汇总花费、销售额、ROAS、ACOS、转化率，异常提醒 | 调预算、暂停、扩词 | **已有**（ads_daily + 广告投放页） | 不改，数据直接回流 |
| 达人建联 | 自动筛选达人、打标签、生成西语私信、跟进节奏、寄样状态 | 首次外联确认、佣金、寄样与合同 | 无 | ✅ 新增 `influencer_deal` |
| 素材生产 | 从商品卖点自动生成脚本、分镜、标题、字幕、西语口播、多视频变体 | 品牌调性、广告合规、最终素材 | 无 | ✅ 新增 `material_asset` |

| 视频发布 | 内容排期、自动生成标题/标签/商品挂车草稿，发布后回收表现 | 最终发布与平台政策检查 | 无 | ✅ 新增 `video_publish` |
| 利润与库存 | 自动计算月利润、库存周转、补货建议、滞销与断货预警 | 补货金额与采购决策 | **已有**（inventory + 预警 + 复盘周报 + 订单财务） | 不改，数据直接回流 |

## 三、数据模型（第一期数据底座，已落地）

每个 SKU 唯一编码（`sku_master.sku_code` UNIQUE），六张新表全部以 `sku_code` 外键式挂接：

| 表 | 对应环节 | 关键字段 |
|---|---|---|
| `sku_master` | SKU 主数据中心 | 编码、品名、类目、平台、生命周期（选品池→测试中→在售→清仓→停止）、成本、目标价、首批数量 |
| `selection_research` | 选品分析 | 来源、竞品价、30天销量、评分、关键词、竞品、趋势、**机会评分**、人工判定、目标售价 |
| `listing_task` | 商品上架 + 链接完善 | 类型（上架生成/链接体检）、平台、Listing ID、标题/描述/属性/图片（生成稿）、体检问题、状态 |
| `material_asset` | 素材生产 | 类型（脚本/分镜/标题/字幕/西语口播/视频变体）、内容、变体数、来源、状态 |
| `influencer_deal` | 达人建联 | 达人、平台、地区、粉丝量、标签、西语私信生成稿、跟进日期、状态、佣金/寄样、合同 |
| `video_publish` | 视频发布 | 关联素材、平台、排期、标题/标签/挂车草稿、发布状态、播放、带动 GMV |

数据回流不重复建表：`sales_daily` / `ads_daily` / `inventory` 按 `sku` 聚合出
近 30 天销售额、广告花费、ROAS 与最新库存快照（可售天数 / 库龄），挂到链路总览与单 SKU 档案上。

## 四、分期计划

### 第一期 · 数据底座（✅ 本次已落地）
- SKU 唯一编码 + 六张核心表 + 增长中枢页面（链路总览 / 五个环节 CRUD / 单 SKU 全链路档案）
- 存量租户库自动补表（applySchema 幂等），老数据零迁移成本

### 第二期 · 半自动化把关节点
- 链接体检任务自动生成：从 ads_daily 的低 CTR 主图、order_finance 的差评/退款聚集 SKU 自动出「修改任务」
- 达人跟进节奏提醒：follow_up_date 到期自动进入当日待办
- 补货建议：日均销量 × 备货周期 vs 可售库存，给出建议补货量（人工确认金额）
- 月利润核算表：按 SKU × 月聚合订单财务 + 广告 + 库存仓储费

### 第三期 · 深自动化（对接外部能力）
- 竞品/关键词数据抓取导入（或第三方工具 API），机会评分自动计算
- Listing 文案与素材生成对接 LLM（西语标题/脚本/口播稿），人工确认后进 `listing_task` / `material_asset`
- 发布对接：TikTok Shop / Temu 平台 API 推送草稿，发布后表现自动回写 `video_publish`
- 预警与经营看板打通：链路卡点（长时间停在「待人工确认」的记录）进入看板告警

## 五、使用方式

前端菜单「**增长中枢**」：
1. **SKU 主数据**：先录入 SKU（唯一编码），后续所有环节围绕它展开
2. **选品研究**：录入竞品数据与机会评分，人工判定「采购 / 观察 / 放弃」
3. **商品与链接**：上架生成稿与链接体检任务，人工确认后置「已上架」
4. **达人建联 / 素材库 / 视频发布**：按环节推进，状态即把关节点
5. **链路总览**：每个 SKU 一行，看到卡在哪个环节 + 30 天回流表现；点行看全链路档案
